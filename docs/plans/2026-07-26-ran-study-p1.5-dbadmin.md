# ran-study P1.5 数据库管理 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已安装的 MySQL 实例上提供「建库 / 改 root 密码 / 执行 SQL / 备份(mysqldump) / 导入」可视化数据库管理。

**Architecture:** 新增 `dbadmin.rs`：用 `mysql.exe`/`mysqldump.exe`（位于 MySQL 安装目录 bin）执行操作，密码经 `MYSQL_PWD` 环境变量传递（不落命令行）。root 密码存 `mysql_secrets(software_id, root_password)` 表（安装后为空 = 无密码）。命令层 `commands/dbadmin.rs` 装载 MySQL 实例 spec + root pw 后调用。前端新增「数据库」视图：实例下拉 + 建库/改密/SQL 执行/备份导入。

**Tech Stack:** Rust（std::process Command 调 mysql/mysqldump）+ TS（Vue3/TSX/Element Plus）

**关联：** spec §7.1（建库/改 root 密码/命令行/备份导入）。

**验证策略：** 纯逻辑（SHOW DATABASES 解析、建库 SQL 拼装）走单测；真实操作需运行中的 MySQL，为 `pnpm tauri dev` 人工验收。

## Task P1.5-1: dbadmin.rs

**Files:** `dbadmin.rs`；`lib.rs` 加 `mod dbadmin;`

```rust
use crate::error::{RanError, RanResult};
use crate::provider::SoftwareSpec;
use std::path::PathBuf;
use std::process::{Command, Stdio};

fn mysql_exe(spec: &SoftwareSpec) -> PathBuf {
    spec.bin_path.parent().unwrap().join(if cfg!(windows) { "mysql.exe" } else { "mysql" })
}
fn mysqldump_exe(spec: &SoftwareSpec) -> PathBuf {
    spec.bin_path.parent().unwrap().join(if cfg!(windows) { "mysqldump.exe" } else { "mysqldump" })
}

fn base(exe: &PathBuf, spec: &SoftwareSpec, pw: &str) -> Command {
    let mut c = Command::new(exe);
    c.args([
        "-u", "root", "-h", "127.0.0.1", "-P", &spec.port.to_string(),
        "--default-character-set=utf8mb4",
    ]);
    if !pw.is_empty() {
        c.env("MYSQL_PWD", pw);
    }
    c
}

fn check(out: std::process::Output) -> RanResult<String> {
    if !out.status.success() {
        return Err(RanError::Other(String::from_utf8_lossy(&out.stderr).to_string()));
    }
    Ok(String::from_utf8_lossy(&out.stdout).to_string())
}

pub fn run_query(spec: &SoftwareSpec, pw: &str, sql: &str) -> RanResult<String> {
    let out = base(&mysql_exe(spec), spec, pw).args(["-e", sql]).output()?;
    check(out)
}

pub fn list_databases(spec: &SoftwareSpec, pw: &str) -> RanResult<Vec<String>> {
    let text = run_query(spec, pw, "SHOW DATABASES")?;
    Ok(parse_databases(&text))
}

pub fn parse_databases(text: &str) -> Vec<String> {
    text.lines()
        .skip(1)
        .map(|l| l.trim().to_string())
        .filter(|n| !n.is_empty() && !is_system_db(n))
        .collect()
}

fn is_system_db(name: &str) -> bool {
    matches!(name.to_ascii_lowercase().as_str(),
        "information_schema" | "mysql" | "performance_schema" | "sys")
}

pub fn create_database(spec: &SoftwareSpec, pw: &str, name: &str, user_pw: &Option<String>) -> RanResult<()> {
    let mut sql = format!(
        "CREATE DATABASE IF NOT EXISTS `{n}` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;",
        n = name
    );
    if let Some(p) = user_pw {
        sql.push_str(&format!(
            "CREATE USER IF NOT EXISTS '{n}'@'localhost' IDENTIFIED BY '{p}'; \
             GRANT ALL PRIVILEGES ON `{n}`.* TO '{n}'@'localhost'; FLUSH PRIVILEGES;",
            n = name, p = p
        ));
    }
    run_query(spec, pw, &sql)?;
    Ok(())
}

pub fn change_root_password(spec: &SoftwareSpec, old_pw: &str, new_pw: &str) -> RanResult<()> {
    run_query(
        spec, old_pw,
        &format!("ALTER USER 'root'@'localhost' IDENTIFIED BY '{p}'; FLUSH PRIVILEGES;", p = new_pw),
    )
}

pub fn backup(spec: &SoftwareSpec, pw: &str, db: &str, dest: &std::path::Path) -> RanResult<()> {
    let out = base(&mysqldump_exe(spec), spec, pw)
        .args(["--databases", db]).output()?;
    let _ = check(out)?;
    std::fs::write(dest, check_output_only)?;
    Ok(())
}
// 注：backup 实现见下（check 返回 stdout，再写盘）

pub fn import(spec: &SoftwareSpec, pw: &str, db: &str, src: &std::path::Path) -> RanResult<()> {
    let f = std::fs::File::open(src)?;
    let st = base(&mysql_exe(spec), spec, pw).arg(db).stdin(Stdio::from(f)).status()?;
    if !st.success() { return Err(RanError::Other("mysql 导入失败".into())); }
    Ok(())
}

mod tests {

    #[test]

        let text = "Database\ninformation_schema\nmysql\nmydb\napp\ntest\n";
        let v = parse_databases(text);
        assert_eq!(v, vec!["mydb", "app", "test"]);
    }
    #[test]

        // 间接验证：create_database 拼装的 SQL 应含 CREATE DATABASE 与 GRANT

    }
    fn dummy_spec() {}
}
```

```rust
pub fn get_root_pw(&self, software_id: i64) -> RanResult<String> {
    let conn = self.conn.lock().unwrap();
    let pw: Option<String> = conn.query_row(
        "SELECT root_password FROM mysql_secrets WHERE software_id=?1",
        rusqlite::params![software_id], |r| r.get(0)).ok();
    Ok(pw.unwrap_or_default())
}
pub fn set_root_pw(&self, software_id: i64, pw: &str) -> RanResult<()> {
    self.conn.lock().unwrap().execute(
        "INSERT INTO mysql_secrets(software_id, root_password) VALUES (?1,?2)
         ON CONFLICT(software_id) DO UPDATE SET root_password=excluded.root_password",
        rusqlite::params![software_id, pw])?;
    Ok(())
}
```

## Task P1.5-3: commands/dbadmin.rs + 注册

**Files:** `commands/dbadmin.rs`；`commands/mod.rs` 加 `pub mod dbadmin;`；`lib.rs` 注册命令

```rust
use super::AppState;
use crate::dbadmin;
use crate::error::{RanError, RanResult};
use std::sync::Arc;
use tauri::State;

fn load_mysql(state: &State<'_, Arc<AppState>>, id: i64) -> RanResult<crate::provider::SoftwareSpec> {
    state.repo.list_software()?.into_iter()
        .find(|s| s.id == id && s.provider == "mysql")
        .ok_or_else(|| RanError::NotFound(format!("mysql {id}")))
}

#[tauri::command]
pub fn list_mysql_databases(state: State<'_, Arc<AppState>>, id: i64) -> RanResult<Vec<String>> {
    let spec = load_mysql(&state, id)?;
    let pw = state.repo.get_root_pw(id)?;
    dbadmin::list_databases(&spec, &pw)
}
#[tauri::command]
pub fn create_mysql_database(state: State<'_, Arc<AppState>>, id: i64, name: String, password: Option<String>) -> RanResult<()> {
    let spec = load_mysql(&state, id)?;
    let pw = state.repo.get_root_pw(id)?;
    dbadmin::create_database(&spec, &pw, &name, &password)
}
#[tauri::command]
pub fn change_root_password(state: State<'_, Arc<AppState>>, id: i64, newPassword: String) -> RanResult<()> {
    let spec = load_mysql(&state, id)?;
    let old = state.repo.get_root_pw(id)?;
    dbadmin::change_root_password(&spec, &old, &newPassword)?;
    state.repo.set_root_pw(id, &newPassword)
}
#[tauri::command]
pub fn backup_mysql(state: State<'_, Arc<AppState>>, id: i64, db: String, dest: String) -> RanResult<()> {
    let spec = load_mysql(&state, id)?;
    let pw = state.repo.get_root_pw(id)?;
    dbadmin::backup(&spec, &pw, &db, std::path::Path::new(&dest))
}
#[tauri::command]
pub fn import_mysql(state: State<'_, Arc<AppState>>, id: i64, db: String, src: String) -> RanResult<()> {
    let spec = load_mysql(&state, id)?;
    let pw = state.repo.get_root_pw(id)?;
    dbadmin::import(&spec, &pw, &db, std::path::Path::new(&src))
}
#[tauri::command]
pub fn run_mysql_query(state: State<'_, Arc<AppState>>, id: i64, sql: String) -> RanResult<String> {
    let spec = load_mysql(&state, id)?;
    let pw = state.repo.get_root_pw(id)?;
    dbadmin::run_query(&spec, &pw, &sql)
}
```
